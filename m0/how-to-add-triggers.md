# 如何自己添加触发码

> 适用 Espanso 2.4.1 / Windows 11。本文所有命令和结论都已在本机实测过。

## 总览：四步

1. 改文件
2. **重启**（不能省）
3. 确认加载上了
4. 试一下

---

## 第 1 步：打开配置文件

在资源管理器**地址栏**粘贴这个路径（`%APPDATA%` 会自动展开）：

```
%APPDATA%\espanso\match
```

用记事本打开 `espanso-shizi-m0.yml`。

完整路径是：
`%APPDATA%\espanso\match\espanso-shizi-m0.yml`

## 第 2 步：在文件末尾加一段

```yaml
  - trigger: ";abc"
    replace: "要插入的内容"
```

就这两行。三条硬规则：

| 规则 | 说明 |
|---|---|
| **缩进必须是 2 个空格** | 绝对不能用 Tab。这是 YAML 报错的第一大原因 |
| **trigger 和 replace 都加英文双引号** | 内容含空格、冒号、`*`、`#` 时必须加，不加容易出错，不如一律加上 |
| **不能有重复的触发码** | 同一个触发码写两次，只有一条会生效 |

## 第 3 步：重启（实测：这步不能省）

**Espanso 不会自动重载配置。** 我实测过：改完文件等 6 秒，新条目依然没加载。

新开一个终端窗口，输入：

```
espanso service restart
```

约 1 秒完成，正常返回。

> 如果提示「`espanso` 不是内部或外部命令」，说明这个终端窗口是在 PATH 更新之前打开的。
> 用完整路径代替：
> ```
> %LOCALAPPDATA%\Programs\Espanso\espanso.cmd service restart
> ```

## 第 4 步：确认加载上了

```
espanso match list
```

在输出里找到你刚加的那一行。

- **看得到 → 成功了**
- 看不到 → 出错了，看下面的「出错怎么查」

---

## 特殊字符怎么写

如果内容里有**看不见的字符**，或者**长得一样但编码不同的字符**，直接敲进去你自己也分不清对错。用 `\uXXXX` 写法：

| 想插入 | 写法 | 说明 |
|---|---|---|
| 不换行空格 | `"\u00A0"` | 排版用，肉眼看不见 |
| 零宽空格 | `"\u200B"` | 宽度为零，肉眼看不见 |
| 全角空格 | `"\u3000"` | 一个汉字的宽度 |
| × 乘号 / 杂交号 | `"\u00D7"` | 和字母 x 完全不同 |
| µ 微符号 | `"\u00B5"` | 单位用（µm） |
| μ 希腊 mu | `"\u03BC"` | 和上面那个**不是同一个字符** |
| ℃ 摄氏度 | `"\u2103"` | 单码点字符 |
| —— 破折号 | `"\u2014\u2014"` | 是两个 U+2014 |
| ≤ ≥ ≈ ± ÷ | `"\u2264"` `"\u2265"` `"\u2248"` `"\u00B1"` `"\u00F7"` | 数学符号 |

**判断标准：只要这个字符你肉眼分不出对错，就用 `\uXXXX`。** 中文汉字直接敲没问题。

## 出错怎么查

### 症状 A：`match list` 里看不到新条目

1. 看日志，最后 30 行通常直接写着原因：
   ```
   espanso log
   ```
   或直接打开 `%LOCALAPPDATA%\espanso\espanso.log`
2. **九成是缩进问题**——检查是不是混进了 Tab，或者空格数不对（必须和相邻条目的 `- trigger` 对齐）
3. 剩下的是双引号没配对

### 症状 B：`match list` 里有，但打字不展开

- 确认 Espanso 正在运行：`espanso service status`，或看托盘区有没有图标
- 确认触发码没打错（注意 `;` 是英文分号，不是中文分号 `；`）
- 个别程序会拦截输入，换个地方试（记事本最保险）

### 症状 C：提示 espanso 命令找不到

用完整路径：`%LOCALAPPDATA%\Programs\Espanso\espanso.cmd <子命令>`

### 改坏了想退回

配置文件在 `outputs\phrase-tool\m0\` 下有一份同步副本，可以对照。
最坏情况：把 `espanso-shizi-m0.yml` 整个删掉再重启，Espanso 会忽略它，程序照常运行。

---

## 三条避坑提醒

**1. 触发码一律用 `;` 开头**

反面案例：直接用 `KX` 做触发码，会跟你自己手打的 `B456` 撞车。
`;` 开头的码不会和英文单词或编号撞车。你现有的 27 条全是这个风格，保持一致。

**2. 触发码不能是另一条的开头**

已有 `;xila`（希腊字母表），你就不能再用 `;x`——两者会互相干扰。
批量加之前，先 `espanso match list` 扫一眼有没有谁是谁的前缀。

**3. 删条目 = 直接删掉那两行，然后同样要重启**

别忘了重启。删了不重启，旧的照样生效。

## 批量添加

一次加 20 条也是同样的做法：全部写完，**只重启一次**。不用加一条重启一次。

格式就是重复这个块：

```yaml
  - trigger: ";码1"
    replace: "内容1"
  - trigger: ";码2"
    replace: "内容2"
```

注意每条的 `- trigger` 前面都是两个空格，同一个缩进层级。
